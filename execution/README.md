# execution/

Questa cartella contiene script Python deterministici usati dagli agenti.

Gli script devono essere:

- chiari;
- riutilizzabili;
- testabili;
- commentati quando serve;
- privi di credenziali hardcoded;
- progettati per input/output prevedibili.

Prima di creare un nuovo script, verificare se ne esiste già uno adatto.
